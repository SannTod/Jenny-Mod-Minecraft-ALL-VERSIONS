**Step 2: Find Your Minecraft Folder**
1. Press the **Windows key** and the **R key** at the same time
2. Type `%appdata%` and press Enter
3. Open the folder called `.minecraft`
4. If you don't see it, look for a folder named `minecraft`

**Step 3: Create the Mods Folder**
1. Inside the `.minecraft` folder, look for a folder called `mods`
2. If you see it, great! Open it
3. If not, right-click and choose "New Fold" > "Folder"
4. Name it exactly: `mods`

**Step 4: Install Forge (If You Don't Have It)**
1. Go to the Forge website and download the installer for your Minecraft version
2. Run the installer and choose "Install Client"
3. Open the Minecraft launcher
4. Select the Forge version from the dropdown menu
5. Click "Play" once to let it finish setting up

**Step 5: Add Jenny to Your Game**
1. Take the Jenny mod file you downloaded earlier
2. Copy it (right-click > Copy)
3. Paste it into the `mods` folder (right-click > Paste)
4. Done! The file is now in place

**Step 6: Launch and Play**
1. Open the Minecraft launcher
2. Make sure "Forge" is selected in the version dropdown
3. Click "Play"
4. Wait for the game to load - it might take a little longer this first time
5. Start a new world or load an existing one
6. Type `/summon jenny` in the chat to bring her in
